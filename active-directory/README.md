# Active Directory

Documentação de estudos e atividades relacionadas à administração de ambientes Active Directory.

## Tópicos

- Criação de usuários
- Grupos
- Permissões
- Organizational Units (OU)
- Group Policy Objects (GPO)
- Controle de acesso

## Objetivo

Documentar conhecimentos e práticas relacionadas à gestão de identidades e acessos em ambientes corporativos.
