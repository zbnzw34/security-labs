# Controle de Acesso

## Objetivo

Documentar conceitos relacionados ao controle de acesso em ambientes corporativos.

## Conhecimentos Aplicados

### Gestão de Identidades

Administração de contas de usuários durante todo o ciclo de vida.

Processos comuns:

* Criação de usuários
* Alteração de permissões
* Bloqueio de contas
* Remoção de acessos

### Autenticação

Validação da identidade dos usuários através de credenciais corporativas.

### Autorização

Definição dos recursos que cada usuário pode acessar.

## Boas Práticas

* Aplicação do menor privilégio
* Revisões periódicas de acesso
* Segregação de funções
* Auditoria de alterações

## Relação com Segurança da Informação

O controle de acesso é um dos principais mecanismos de proteção dos recursos corporativos e redução de riscos internos.
