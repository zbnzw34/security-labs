# Usuários e Grupos no Active Directory

## Objetivo

Documentar conceitos e atividades relacionadas à administração de usuários e grupos em ambientes Active Directory.

## Conhecimentos Aplicados

### Criação de Usuários

Criação de contas de usuários seguindo padrões organizacionais, definindo atributos como:

* Nome completo
* Login de usuário
* Unidade Organizacional (OU)
* Senha inicial
* Política de troca de senha

### Gerenciamento de Grupos

Utilização de grupos para simplificar o gerenciamento de permissões e acessos.

Exemplos:

* Grupo Financeiro
* Grupo RH
* Grupo TI
* Grupo Diretoria

### Controle de Acesso

Aplicação do princípio do menor privilégio, concedendo apenas os acessos necessários para execução das atividades dos usuários.

### Bloqueio e Desbloqueio de Contas

Procedimentos para tratamento de contas bloqueadas, redefinição de senhas e restauração de acesso.

## Boas Práticas

* Utilizar grupos ao invés de permissões individuais
* Revisar permissões periodicamente
* Remover acessos desnecessários
* Aplicar políticas de senha adequadas
* Registrar alterações relevantes

## Relação com Segurança da Informação

O gerenciamento adequado de usuários e grupos é fundamental para:

* Controle de acesso
* Gestão de identidades
* Redução de privilégios excessivos
* Atendimento a requisitos de auditoria
* Segurança de ambientes corporativos
