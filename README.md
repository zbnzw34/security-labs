# Security Labs

Repositório destinado à documentação de laboratórios, estudos e projetos relacionados à Segurança da Informação.

## Sobre

Sou profissional de TI com formação em Segurança da Informação e atualmente cursando Pós-Graduação em Offensive Cyber Security pela FIAP.

Este repositório reúne estudos práticos realizados em laboratórios, ambientes de testes e plataformas de treinamento, com foco em segurança ofensiva e defensiva.

## Áreas de Estudo

* Pentest Web
* Pentest de Infraestrutura
* Linux
* Active Directory
* Redes
* Hardening
* Monitoramento e SOC
* Análise de Vulnerabilidades

## Estrutura

### Hack The Box

Documentação dos laboratórios concluídos e principais conceitos praticados.

### Active Directory

Estudos relacionados a controle de acesso, usuários, grupos, permissões e políticas.

### Linux

Hardening, administração e segurança de sistemas Linux.

### Networking

Protocolos, serviços e fundamentos de redes aplicados à Segurança da Informação.

## Objetivo

Consolidar conhecimentos técnicos, documentar aprendizados e construir um portfólio profissional voltado para a área de Cyber Security.
