# Sequel

## Objetivo

Laboratório focado em enumeração e interação com bancos de dados.

## Competências Praticadas

* Enumeração de serviços
* Identificação de banco de dados exposto
* Interação com ambiente SQL
* Coleta de informações

## Ferramentas Utilizadas

* Nmap
* Cliente SQL
* Linux

## Aprendizados

* Importância da proteção de bancos de dados
* Enumeração de serviços SQL
* Boas práticas de segurança para serviços de banco de dados
