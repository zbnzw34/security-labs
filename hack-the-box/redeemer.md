# Redeemer

## Objetivo

Laboratório focado na enumeração e exploração de serviços Redis expostos.

## Competências Praticadas

* Enumeração de serviços
* Identificação de Redis exposto
* Coleta de informações
* Análise de configurações inseguras

## Ferramentas Utilizadas

* Nmap
* Redis CLI
* Linux

## Aprendizados

* Riscos relacionados à exposição de serviços Redis
* Importância da segmentação de rede
* Controle adequado de acesso a serviços críticos
