# Hack The Box

Documentação dos laboratórios concluídos na plataforma Hack The Box.

## Máquinas Documentadas

- Meow
- Fawn
- Dancing
- Redeemer
- Appointment
- Sequel
- Cap

## Competências Trabalhadas

- Enumeração de serviços
- Reconhecimento de superfície de ataque
- Análise de vulnerabilidades
- Segurança Web
- Bancos de Dados
- Protocolos de Rede
- Escalação de Privilégios
- Análise de Tráfego

## Objetivo

Registrar os conhecimentos adquiridos durante os laboratórios, destacando competências praticadas, ferramentas utilizadas e principais aprendizados relacionados à Segurança da Informação.
